# Nicolas Miss — Creative Portfolio

Site estático pronto para GitHub Pages. Não precisa de Node.js, npm ou processo de build.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Extraia este ZIP no computador.
3. Envie **o conteúdo desta pasta diretamente para a raiz do repositório**: `index.html`, `styles.css`, `script.js`, `assets/`, `.nojekyll` e este README.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/(root)`, depois salve.

Importante: não envie a pasta externa como uma subpasta do repositório. O `index.html` e a pasta `assets` precisam ficar lado a lado na raiz.

Todos os caminhos de arquivos locais usam `./` para funcionar também em URLs de projeto do GitHub Pages, por exemplo `https://usuario.github.io/nome-do-repositorio/`.

## Testar localmente

Basta abrir `index.html` no navegador. Se preferir, execute `INICIAR.bat` (Windows).
